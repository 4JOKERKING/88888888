# 何志 · 前端开发指南

## 技术栈
Vue 3 + TypeScript + Vite + Pinia + Element Plus + ECharts

## 分支
`feature/frontend`

## 命名
- 组件：`PascalCase`（如 `DiagnosisUpload.vue`）
- 文件：`kebab-case`（如 `api/diagnosis.ts`）
- 缩进：2 空格

## 启动
```bat
cd frontend
npm install
npm run dev
```

默认地址：http://localhost:5173  
演示账号（密码均为 `123456`）：`farmer` / `tech` / `coop` / `admin`

当前 `VITE_USE_MOCK=true`，无后端也可演示。后端就绪后改为 `false`。

## 6 个页面（对齐选题三）

| # | 页面 | 路径 | 覆盖期末要求 |
|---|------|------|-------------|
| 1 | 登录 | `/login` | 农户/农技/合作社/管理员四类角色 |
| 2 | 态势大屏 | `/dashboard` | 天气、病虫害、市场价格趋势图 |
| 3 | 农场档案 | `/archive` | 农场、地块、种植档案管理 |
| 4 | 智能诊断 | `/diagnosis` | 图片上传、结果可视化、规范原文对照、审核 |
| 5 | 农事日历 | `/calendar` | 农事日历与待办任务 |
| 6 | 模型监控 | `/monitor` | 模型性能、数据漂移、未知样本监控 |
