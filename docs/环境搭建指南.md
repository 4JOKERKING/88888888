## 第零步：GitHub 协作环境配置（所有人必须先做）

这是最重要的一步。做完这步才能 Clone 项目代码。

### 0.1 安装 Git

1. 下载：https://git-scm.com/download/win
2. 安装：一路默认，遇到"选择默认编辑器"时选 VS Code
3. 验证：
```bash
git --version
# 应输出：git version 2.xx.x
```

### 0.2 配置 Git 用户名和邮箱

打开终端（在文件夹空白处右键 → "Git Bash Here" 或 "Open in Terminal"），执行：

```bash
git config --global user.name "你的姓名拼音"
git config --global user.email "你的邮箱"
```

例如：
```bash
git config --global user.name "lijayu"
git config --global user.email "lijayu@example.com"
```

### 0.3 生成 SSH Key

在终端执行（一路回车，不要设密码）：

```bash
ssh-keygen -t ed25519 -C "你的GitHub邮箱"
```

执行后会显示：
```
Generating public/private ed25519 key pair.
Enter file in which to save the key (C:\Users\你的用户名/.ssh/id_ed25519):   ← 直接回车
Enter passphrase (empty for no passphrase):   ← 直接回车
Enter same passphrase again:   ← 直接回车
```

### 0.4 复制公钥

```bash
cat ~/.ssh/id_ed25519.pub
```

会输出一段以 `ssh-ed25519` 开头、以你的邮箱结尾的字符串，**全选复制**。

### 0.5 把公钥发给组长（李珈逾）

把上一步复制的公钥通过微信/QQ 发给李珈逾。

**组长操作**（只有李珈逾需要做）：
1. 打开 https://github.com/4JOKERKING/88888888/settings/keys
2. 点 "Add deploy key"（或让组员自己去 https://github.com/settings/keys 添加）
3. 标题填组员名字（如 "何志"），粘贴公钥，勾选 "Allow write access"，点 Add key

> 更推荐的做法：让组员自己去 https://github.com/settings/keys 添加（Settings → SSH and GPG keys → New SSH key），然后李珈逾去仓库 Settings → Collaborators → Add people 把组员加为协作者。

### 0.6 验证 SSH 连接

```bash
ssh -T git@github.com
```

看到 `Hi xxx! You've successfully authenticated` 就说明成功了。

### 0.7 Clone 项目到本地

```bash
cd "C:\Users\你的用户名\Desktop"
git clone git@github.com:4JOKERKING/88888888.git 期末大作业
```

### 0.8 创建你自己的分支

```bash
cd "C:\Users\你的用户名\Desktop\期末大作业"

# 何志：
git checkout -b feature/frontend

# 莫成兴：
git checkout -b feature/backend

# 李珈逾：
git checkout -b feature/ai-service

# 陶柱宏：
git checkout -b feature/deploy-docs
```

### 0.9 安装 VS Code

1. 下载：https://code.visualstudio.com/
2. 必装插件（点左侧扩展图标搜索安装）：
   - **Chinese (Simplified)** — 中文界面
   - **GitLens** — Git 增强
   - **Prettier** — 代码格式化

## 各角色开发环境

> 按你的角色来，不用全装。只装你负责的那部分。

### 何志 — 前端开发环境

#### 1. Node.js 18+
下载：https://nodejs.org/en/download/
选 **LTS 版本**（18.x 或 20.x），安装时全部默认。

验证：
```bash
node --version   # v18.xx.x 或 v20.xx.x
npm --version    # 10.x.x
```

#### 2. 创建 Vue 3 项目
```bash
cd "C:\Users\你的用户名\Desktop\期末大作业"
npm create vite@latest frontend -- --template vue-ts
cd frontend
npm install
npm install element-plus echarts pinia vue-router axios
npm run dev
# 浏览器打开 http://localhost:5173/ 看到 Vite 页面即成功
```

#### 3. 推荐 VS Code 插件
- **Vue - Official**（原 Volar）
- **ESLint**

### 莫成兴 — 后端开发环境

#### 1. JDK 17
下载：https://adoptium.net/
选 **Temurin 17 (LTS)**，Windows x64 安装包。

验证：
```bash
java --version   # openjdk 17.0.x
javac --version
```

#### 2. Maven
下载：https://maven.apache.org/download.cgi
选 **Binary zip archive**，解压到 `C:\apache-maven-3.9.x`

配置环境变量（Win+R → sysdm.cpl → 高级 → 环境变量）：
- 系统变量 Path 添加 `C:\apache-maven-3.9.x\bin`

验证：
```bash
mvn --version   # Apache Maven 3.9.x
```

#### 3. MySQL 8.0
下载：https://dev.mysql.com/downloads/installer/
选 **mysql-installer-community**，安装时选 Server Only，记住 root 密码。

或用 XAMPP（更简单）：https://www.apachefriends.org/

验证：
```bash
mysql -u root -p
# 输入密码，看到 mysql> 即成功
```

#### 4. 创建 Spring Boot 项目
打开 https://start.spring.io/
- Project: Maven
- Language: Java
- Spring Boot: 3.2.x
- Group: com.agriculture
- Artifact: backend
- Dependencies 选：**Spring Web, MyBatis Framework, MySQL Driver, Spring Security, Validation**
- 点 Generate 下载，解压到 `期末大作业/backend/`

#### 5. 推荐 IDE
**IntelliJ IDEA Community**（免费）：https://www.jetbrains.com/idea/download/
或直接用 VS Code + **Extension Pack for Java** 插件。

### 李珈逾 — AI 服务开发环境

#### 1. Python 3.10+
下载：https://www.python.org/downloads/
**安装时务必勾选 "Add Python to PATH"** ✅

验证：
```bash
python --version   # Python 3.10.x 或 3.11.x
pip --version
```

#### 2. 创建项目并安装依赖
```bash
cd "C:\Users\你的用户名\Desktop\期末大作业"
mkdir ai-service
cd ai-service
python -m venv venv

# 激活虚拟环境（每次打开终端都要跑这行）
venv\Scripts\activate

# 安装依赖
pip install fastapi uvicorn python-multipart langchain langchain-community chromadb openai pillow httpx
```

#### 3. 验证 FastAPI 能跑
创建 `main.py`：
```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/api/health")
def health():
    return {"status": "ok", "model_loaded": True}
```

运行：
```bash
uvicorn main:app --reload --port 8000
# 浏览器打开 http://localhost:8000/api/health 看到 JSON 即成功
```

#### 4. 推荐 VS Code 插件
- **Python** (Microsoft)
- **Pylance**

### 陶柱宏 — 部署 + 文档环境

#### 1. Docker Desktop
下载：https://www.docker.com/products/docker-desktop/
安装后重启电脑，打开 Docker Desktop 等它启动完成。

验证：
```bash
docker --version
docker compose version
```

> ⚠️ 如果 Docker Desktop 装不了或启动不了（Windows 版本问题），先跳过，到时候用本地开发模式，最后再统一处理部署。

#### 2. Python 3.10+（用于数据采集管道）
安装方式同李珈逾的 Python 部分。

```bash
pip install httpx schedule
```

#### 3. 文档工具
- **VS Code** + Markdown 预览（内置即可）
- 或 **Typora**（更好看的 Markdown 编辑器）：https://typora.io/
