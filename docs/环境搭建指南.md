# 环境搭建指南

> 每个人在自己的 Windows 电脑上安装对应工具。**按你的角色来，不用全装。**

---

## 通用工具（所有人都装）

### Git
1. 下载：https://git-scm.com/download/win
2. 安装：一路默认，遇到"选择默认编辑器"时选 VS Code
3. 验证：
```bash
git --version
# 应输出：git version 2.xx.x
```

### VS Code
1. 下载：https://code.visualstudio.com/
2. 必装插件（点左侧扩展图标搜索安装）：
   - **Chinese (Simplified)** — 中文界面
   - **GitLens** — Git 增强
   - **Prettier** — 代码格式化

### GitHub 账号
1. 如果没有，去 https://github.com 注册
2. 在 VS Code 里登录 GitHub（左下角账户图标）

## A — 前端开发环境

### 1. Node.js 18+
下载：https://nodejs.org/en/download/
选 **LTS 版本**（18.x 或 20.x），安装时全部默认。

验证：
```bash
node --version
# v18.xx.x 或 v20.xx.x
npm --version
# 10.x.x
```

### 2. 创建 Vue 3 项目
```bash
cd "C:\Users\你的用户名\Desktop\期末大作业"
npm create vite@latest frontend -- --template vue-ts
cd frontend
npm install
npm install element-plus echarts pinia vue-router axios
npm run dev
# 浏览器打开 http://localhost:5173/ 看到 Vite 页面即成功
```

### 3. 推荐 VS Code 插件
- **Vue - Official** (原 Volar)
- **ESLint**

## B — 后端开发环境

### 1. JDK 17
下载：https://adoptium.net/
选 **Temurin 17 (LTS)**，Windows x64 安装包。

验证：
```bash
java --version
# openjdk 17.0.x ...
javac --version
```

### 2. Maven
下载：https://maven.apache.org/download.cgi
选 **Binary zip archive**，解压到 `C:\apache-maven-3.9.x`

配置环境变量（Win+R → sysdm.cpl → 高级 → 环境变量）：
- 系统变量 Path 添加 `C:\apache-maven-3.9.x\bin`

验证：
```bash
mvn --version
# Apache Maven 3.9.x
```

### 3. MySQL 8.0
下载：https://dev.mysql.com/downloads/installer/
选 **mysql-installer-community**，安装时选 Server Only，记住 root 密码。

或用 XAMPP（更简单）：https://www.apachefriends.org/

验证：
```bash
mysql -u root -p
# 输入密码，看到 mysql> 即成功
```

### 4. 创建 Spring Boot 项目
打开 https://start.spring.io/
- Project: Maven
- Language: Java
- Spring Boot: 3.2.x
- Group: com.agriculture
- Artifact: backend
- Dependencies 选：**Spring Web, MyBatis Framework, MySQL Driver, Spring Security, Validation**
- 点 Generate 下载，解压到 `期末大作业/backend/`

### 5. 推荐 IDE
**IntelliJ IDEA Community**（免费）：https://www.jetbrains.com/idea/download/
或直接用 VS Code + **Extension Pack for Java** 插件。

## C — AI 服务开发环境

### 1. Python 3.10+
下载：https://www.python.org/downloads/
**安装时务必勾选 "Add Python to PATH"** ✅

验证：
```bash
python --version
# Python 3.10.x 或 3.11.x
pip --version
```

### 2. 创建项目并安装依赖
```bash
cd "C:\Users\你的用户名\Desktop\期末大作业"
mkdir ai-service
cd ai-service
python -m venv venv

# 激活虚拟环境（每次打开终端都要跑这行）
venv\Scripts\activate

# 安装依赖
pip install fastapi uvicorn python-multipart langchain langchain-community chromadb openai pillow
```

### 3. 验证 FastAPI 能跑
创建 `main.py`：
```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/api/health")
def health():
    return {"status": "ok", "model_loaded": True}
```

运行：
```bash
uvicorn main:app --reload --port 8000
# 浏览器打开 http://localhost:8000/api/health 看到 JSON 即成功
```

### 4. 推荐 VS Code 插件
- **Python** (Microsoft)
- **Pylance**

```bash

```

```

node_modules/

*.class
*.jar
*.war

# Python
__pycache__/
*.pyc
*.pyo
venv/
.env

# IDE
.idea/
.vscode/
*.swp
*.swo

# OS
.DS_Store
Thumbs.db

# 临时文件
*.log
uploads/
temp/

# Docker
docker-data/
```
